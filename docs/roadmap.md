# 개발 로드맵

작성 기준: 2026-10-13. SING은 장기적으로 발전시킬 프로젝트이며, 수업 발표는 중간 점검 시점이다.

## 현재 상태

| 구분 | 상태 |
| --- | --- |
| 1단계 모바일 웹 | 첫 안내, 편한 시작음 탐색, 짧은 연습, 로컬 기록, 개인 노래장 구현 |
| 피아노 기준음·허밍 안내 | 실제 피아노 샘플과 짧은 텍스트 안내 구현 |
| 자동·브라우저 검사 | 2026-09-28 검증 기록 보유. 최신 확인 결과는 README 참조 |
| Android 실제 마이크 | 완료 증거 없음. 다음 단계의 우선 검증 대상 |
| 생성형 AI 연결 | 미구현 |
| 공개 곡 DB·자동 추천 | 데이터 확보 방법과 범위 검토 중 |

기존 계획서의 9월 말~10월 초 항목을 날짜가 지났다는 이유로 완료 처리하지 않는다. 실제 구현·검증 증거를 기준으로 상태를 갱신한다.

## 수업 발표까지의 제안 일정

아래는 10월 13일 현재 상태에서 정리한 **제안 일정**이다. 실기기 검증과 AI 연결 난이도에 따라 조정하며, 아직 수행하지 않은 작업은 계획으로 유지한다.

| 기간 | 우선 작업 | 완료 기준 / 산출물 |
| --- | --- | --- |
| 10/13~10/19 | 공개 저장소와 문서 정리, Android 마이크·기준음·취소·저장 확인, 음정/안정성 지표 정의 | README·구조도·화면 예시, 기기별 확인 기록, AI 입력 항목 초안 |
| 10/20~10/26 | 측정 지표 화면과 생성형 AI 피드백의 최소 흐름 구현 | 검증 가능한 지표, 서버 API, 결과 설명, 실패 시 기본 안내 |
| 10/27~11/2 | 준비된 연습 목록과 맞춤 안내, 노래장 분류 개선, 곡 데이터 확보 가능성 확인 | 연습 선택 조건, 사용자 분류, 출처 있는 곡 데이터 소규모 검토 |
| 11/3~11/9 | 통합 검증, 오류 처리와 기록 보존 확인, 발표 버전 범위 확정 | 재현 가능한 핵심 시나리오, 수정 내역, 발표 버전 |
| 11/10~11/16 | 슬라이드, 30초 시연 영상, 리허설 | 5분 발표 자료와 시연 영상, 실제 동작/계획 구분 |
| 11/17 | 수업 발표와 피드백 수집 | 발표 및 후속 개발 항목 정리 |

측정이 불안정하면 Android 검증과 지표 보완을 먼저 진행한다. AI 기능은 한 음 연습의 근거 있는 결과 설명부터 완성한다. 곡 데이터 확보가 지연되면 개인 노래장 개선을 진행하고 자동 추천 일정을 조정한다.

## 발표 이후

- 실제 연습 기록을 바탕으로 맞춤 연습 콘텐츠와 다음 과제 선택을 개선한다.
- 곡 데이터의 출처와 비교 기준을 확보하고, 개인 키·체감·취향을 반영한 추천을 확장한다.
- 같은 과제의 전후 녹음 비교와 주간 변화 요약을 검토한다.
- 실제 사용을 보며 PWA 설치, Android 패키징, 기기 간 동기화의 필요성을 판단한다.

최고음 상승이나 연속 출석만을 성과로 삼지 않고, 사용자가 자신에게 맞는 연습을 찾고 이어갈 수 있는지를 확인한다.
