# 친구들과 함께 쓰기 (배포 안내)

처음 작성: 2026-11-17. SING을 무료 서버 한 곳(Render)에 올려 초대받은 친구들이 휴대폰으로 쓰게 하는 방법입니다. 회원가입은 없고, 초대 링크 하나로 들어옵니다. 기록은 지금처럼 각자의 휴대폰에만 남습니다.

## 1. Render에 올리기

1. [render.com](https://render.com)에 GitHub 계정으로 가입합니다. 무료 웹 서비스는 카드 등록 없이 쓸 수 있습니다.
2. 대시보드에서 **New → Blueprint**를 고르고 이 저장소를 고릅니다. 저장소의 `render.yaml`을 읽어 `sing` 서비스(무료, 싱가포르)를 만듭니다.
3. 환경 변수를 넣으라는 칸이 나오면 아래 값을 넣습니다. 키는 이 PC의 `.env`에 있는 값을 그대로 씁니다. 화면에 붙여 넣은 값은 저장소에 올라가지 않습니다.

| 이름 | 넣을 값 |
|---|---|
| `OPENAI_API_KEY` | OpenAI 키 |
| `OPENAI_MODEL` | 사용할 모델(지금은 `gpt-5.5`) |
| `YOUTUBE_API_KEY` | YouTube Data API 키 |
| `INVITE_CODES` | 직접 정한 초대 코드(없으면 서버가 켜지지 않아요). 영문자·숫자·`-`·`_`로 8~64자. 예시 모양: `sing-2026-friends` (예시 그대로 쓰지 말고 새로 정하세요) |
| `ADMIN_KEY` | 사용량을 볼 때 쓰는 열쇠. 16자 이상의 아무 글자 |
| `FEEDBACK_FORM_URL` | 3번에서 만든 설문 링크. 나중에 넣어도 됩니다 |

4. **Apply**를 누르면 몇 분 뒤 `https://sing-xxxx.onrender.com` 같은 주소가 생깁니다.
5. 브라우저에서 `https://주소/api/health`를 열어 `{"ok":true}`가 보이면 서버가 켜진 것입니다.

초대 코드 모양이 틀리면 서버가 켜지지 않고, Render의 **Logs**에 이유가 나옵니다.

## 2. 평가 기간에는 서버 깨워 두기

무료 서버는 15분 동안 아무도 쓰지 않으면 잠들고, 다음 첫 접속이 1분쯤 걸립니다. 저장소의 `.github/workflows/keep-awake.yml`이 한국 시간 오전 9시부터 새벽 2시 전까지 10분마다 서버를 깨웁니다.

1. GitHub 저장소 → **Settings → Secrets and variables → Actions → Variables** 탭 → **New repository variable**
2. 이름 `SING_URL`, 값은 1번에서 받은 주소(`https://sing-xxxx.onrender.com`, 끝에 `/` 없이)
3. **Actions** 탭에서 `keep-awake`가 10분마다 도는지 봅니다. 주소를 넣기 전에도 실패로 끝나지 않습니다.

평가가 끝나면 이 파일을 지우거나 Actions 탭에서 끕니다. 서버가 자더라도 앱 화면은 휴대폰에 보관된 파일로 바로 뜨고, "연습실을 여는 중이에요" 안내가 잠깐 보입니다.

## 3. 구글 설문 만들기

제목은 "SING 써 본 느낌"으로 합니다. **설정**에서 로그인 요구와 이메일 수집을 끕니다. 질문은 다섯 개입니다.

1. **사용 기록 (자동으로 채워져요. 지워도 돼요)** — 단답형, 필수 아님
2. **어디까지 해 봤나요? (해 본 것 모두)** — 체크박스: 허밍 연습 / 곡 담기 / 내 음역 찾기 / AI 추천 받기 / 노래 화면 보기 / 따라 부르기
3. **앱에 얼마나 만족하시나요?** — 선형 배율 1~5
4. **가장 마음에 든 것 하나** — 객관식: 허밍으로 편한 음 찾기 / 내 음역에 맞는 노래방 키 / AI 곡 추천 / 노래 화면(가사·구간) / 따라 부르기 피드백 / 알아두기 칼럼 / 잘 모르겠어요
5. **불편했던 점이나 바라는 점** — 장문형, 필수 아님

설문 편집 화면의 **⋮ → 미리 채워진 링크 가져오기**에서 1번 질문에 `__USAGE__`라고 적고 **링크 가져오기**를 누릅니다. 복사한 링크를 Render의 `FEEDBACK_FORM_URL`에 넣으면, 앱의 "의견 남기기"가 그 자리에 "허밍 3회 · 곡 5개 · 플레이리스트 2개" 같은 사용 요약을 채워서 엽니다. 서버는 이 내용을 받지 않습니다.

## 4. 초대 링크 보내기

초대 링크는 `https://주소/#invite=초대코드` 모양입니다. 링크로 한 번 열면 그 휴대폰에 코드가 저장되고, 주소에서는 코드가 지워집니다.

톡방에 올릴 글 예시:

> 노래 연습 앱 SING을 만들었어요. 써 보고 의견을 남겨 주면 큰 도움이 돼요!
> 미션은 하나: **허밍 한 번 해 보고, 좋아하는 노래 한 곡 담아 보기**
> 링크: https://주소/#invite=초대코드
> 카카오톡 안에서 열리면 "기본 브라우저로 열기"를 눌러 주세요. 다 써 보면 앱 아래쪽의 "의견 남기기"로 1분짜리 설문에 답해 주세요.

## 5. 사용량 보기

`https://주소/api/admin/stats?key=ADMIN_KEY값`을 열면 날짜별로 앱을 쓴 기기 수, AI 요청 수, 영상 찾기 수가 보입니다(최근 30일). 이 숫자는 서버 메모리에만 있어서 서버가 다시 켜지면(배포, Render의 재시작) 0부터 다시 셉니다. 필요하면 그 전에 적어 둡니다. "10명 넘게 써 봤다"의 증빙은 설문 응답 수를 중심으로 합니다.

## 6. 알아 둘 것

- **하루 한도:** 기기 하나는 하루에 AI 요청 30번, 영상 찾기 20번까지 씁니다. 전체 AI 요청은 하루 200번입니다. 넘으면 "오늘 쓸 수 있는 횟수를 다 썼어요"가 보입니다. Render의 환경 변수 `AI_DAILY_LIMIT`, `AI_DEVICE_DAILY_LIMIT`, `VIDEO_DEVICE_DAILY_LIMIT`로 바꿀 수 있습니다.
- **유튜브 할당량:** 영상 찾기는 하루 할당량이 작아서 공개 첫날 저녁에 찰 수 있습니다. 같은 곡은 서버가 일주일 동안 기억해서 다시 찾지 않습니다. 할당량이 차면 링크 붙여넣기로 볼 수 있고, 한국 시간 오후 5시쯤 풀립니다.
- **아이폰:** 사파리에서 쓰던 기록과 홈 화면에 추가한 앱의 기록은 따로 저장됩니다. 홈 화면에 먼저 추가하고 그 아이콘으로 쓰는 것이 좋습니다. 홈 화면 앱을 처음 열면 초대 코드를 한 번 더 묻는데, 카톡으로 받은 초대 링크를 그대로 붙여 넣으면 됩니다. 사파리는 오래 안 쓴 사이트의 저장 내용을 지울 수 있으니 백업을 권합니다.
- **카카오톡:** 카카오톡 안의 브라우저에서는 마이크와 저장이 잘 안 될 수 있어서, 앱이 기본 브라우저로 열자고 안내합니다.
- **초대 코드 바꾸기:** Render의 `INVITE_CODES`만 바꾸면 됩니다. 예전 코드로 들어온 휴대폰은 다음에 열 때 초대 화면이 다시 나옵니다. 코드는 쉼표로 여러 개 둘 수 있습니다.

## 7. 기말 뒤

그대로 두면 됩니다. 비용은 들지 않습니다. 평가 기간에 켠 `keep-awake`만 지웁니다. 키를 바꿨다면 Render의 환경 변수도 같이 바꿉니다.
