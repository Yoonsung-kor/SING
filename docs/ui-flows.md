## 첫 레슨

```mermaid
flowchart TD
    Home[오늘의 연습] --> Check[오늘의 목 상태 확인]
    Check --> Intro[허밍 안내 · 피아노 미리듣기]
    Intro --> Hum[편한 높이에서 짧게 허밍]
    Hum --> Feel[측정 결과 · 직접 느낀 편안함]
    Feel --> Repeat[같은 음 다시 확인]
    Repeat --> Choice[확인한 음에서 마무리 / 반음 상승 선택]
    Choice --> Result[이번에 확인한 음과 체감 정리]
    Result --> Practice[확인된 음에서 짧은 연습]
    Practice --> Save[피드백 · 저장]
    Save --> History[나의 기록 · 다음 회차]
    Check -->|불편함| Rest[발성 중단 · 휴식 안내]
    Feel -->|불편함| Rest
    Repeat -->|측정 부족 / 힘듦 / 모름| Result
```

후속 발성 과제는 반복해서 편하게 확인한 음이 있고 중단 조건에 해당하지 않을 때만 제안한다. 모든 사용자가 같은 단계까지 진행하는 것은 아니다. 미확인 결과도 사실대로 보여주며 재시도와 종료를 허용한다.

| 단계 | 사용자의 행동 | 앱이 보여주는 것 |
| --- | --- | --- |
| 안내 | 목 상태를 선택하고 허밍 설명을 읽는다 | 입술·턱에 대한 간단한 안내, 기준음 미리듣기 |
| 탐색 | 짧게 허밍하고 체감을 선택한다 | 확인한 음 또는 미확인 이유 |
| 재확인 | 같은 음을 다시 내본다 | 반복 확인 여부, 마무리/다음 시도 선택 |
| 연습 | 확인된 음으로 짧게 따라 한다 | 측정 결과와 사용자 체감 |
| 기록 | 저장하고 이전 회차를 확인한다 | 시도별 기록과 주간 활동 |

음높이 숫자를 올리는 것보다 편안함을 확인하고 연습을 이어가는 경험을 우선한다. 결과에서 이번 시도의 확인 음을 사용자의 전체 음역으로 단정하지 않는다.

## ‘뭐 부르지?’

9월의 개인 노래장(불러볼 곡 / 연습 중 / 익숙한 곡)은 11월에 사용자가 이름을 붙이는 **플레이리스트**로 바뀌었다. 지금의 흐름은 다음과 같다.

```mermaid
flowchart TD
    First[뭐 부르지? 처음 들어옴] --> Pick[자신 있는 곡을 검색해 고름 · TJ 노래방 검색 우선]
    Pick --> Top[곡마다 AI가 최고음을 찾고 서버가 출처에서 확인]
    Top --> Range[편하게 내는 최고음을 오선지에 표시 · 직접 고칠 수 있음]
    Range --> List[플레이리스트에 저장 · 이름은 사용자가 정함]
    List -->|곡 3개 이상| Rec[AI 곡 추천 · 곡마다 내게 맞는 노래방 키]
    List --> Song[곡을 열면 노래 화면]
    Song --> Watch[원곡 / 노래방 영상 · 가사 · 구간 이동 · 구간 메모]
    Song --> Sing[이어폰을 끼고 따라 부르기 → 줄별 측정 → AI 피드백]
```

곡은 검색해서 담고, 찾지 못한 곡만 직접 입력한다. 출처에서 확인하지 못한 최고음은 채우지 않는다. AI를 쓰는 기능은 처음 쓸 때 무엇을 보내는지 보여 주고 동의를 받는다.

## 시연 시나리오 초안

사용자: 집에서 혼자 연습하려는 보컬 초보자. 하고 싶은 일: 오늘 편한 시작음을 확인하고 다음에 할 짧은 연습을 찾기.

| 순서 | 보여줄 장면 | 전달할 내용 |
| --- | --- | --- |
| 1 | 홈과 허밍 안내 | 초보자도 짧은 안내로 시작한다 |
| 2 | 피아노 기준음과 한 번의 허밍 | 내장 마이크로 음높이를 확인한다 |
| 3 | 결과와 편안함 입력 | 측정값과 사용자 체감을 함께 본다 |
| 4 | 후속 연습과 기록 | 한 번 측정하고 끝나지 않고 다음 연습으로 이어진다 |
| 5 | 뭐 부르지? | 내 음역을 찾고, AI 추천 곡과 맞는 노래방 키를 본다 |
| 6 | 노래 화면과 따라 부르기 | 구간으로 이동하고, 따라 부른 뒤 어느 줄이 아쉬웠는지 본다 |

2026년 11월 17일 발표의 30초 시연은 이 순서를 녹화한 영상이다. 마이크에는 테스트용 합성 음성을 넣었고 영상에 그 사실을 적었다. 앱 화면과 AI 응답은 실제 동작이다.
